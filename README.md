# Tube Academy Browser

A privacy-focused anti-detect browser with per-profile fingerprints and proxies,
supporting multiple engines including **Camoufox** (stealth Firefox) and a
Chromium engine.

Windows installer is built automatically by GitHub Actions and published under
[Releases](../../releases).
